Control de inventario y trazabilidad

Unidades, donantes y lotes en una sola vista. La información se actualiza automáticamente.

Reservar una unidad

El sistema elige una unidad compatible y la que vence primero (FEFO). Para despacharla, ve a Procesos.

Existencias disponibles

Vista general por tipo y componente. Para explorar las unidades de cada lote, abre Lotes.

Lotes registrados

Selecciona un lote para ver sus unidades reales, existencias y caducidades. Los lotes vacíos o sin unidades disponibles siguen visibles al desactivar el filtro.

Crear un lote

Elige el componente a almacenar. El lote comienza vacío; después añade unidades de donantes registrados.

Añadir una unidad al lote seleccionado

Una unidad por donante y componente en cada lote. La caducidad se calcula automáticamente: rojos 42 días, plasma 365 días o plaquetas 7 días. Si falta el donante, regístralo en Donantes.

Simular falla de refrigerador

Acción irreversible: compromete las unidades del lote. Revisa su contenido antes de confirmar.

Donantes registrados

Los donantes de la simulación original no tienen ficha personal: se muestran su ID, tipo y unidades, sin inventar edad ni peso. Usa solo alias y datos ficticios en altas nuevas.

Registrar donante ficticio

No uses nombres, teléfonos ni datos médicos reales. Edad y peso son opcionales; registrarlos no equivale a certificar aptitud para donar.

Retiro por prueba positiva tardía

Retira las unidades de un donante y reporta las ya despachadas para seguimiento.

Procesos de unidades

Cada fila es un proceso gen_statem. Puedes despachar tu reserva, liberarla o retirar una unidad no entregada.

Bitácora de trazabilidad

Últimos 100 eventos reales. Puedes filtrar por ID de unidad; las asignaciones indican el receptor.
